# E-Commerce Site

A modern e-commerce website built with HTML, Tailwind CSS, and JavaScript.

## Features

- Responsive design
- Dynamic product listing
- Shopping cart functionality
- Checkout process
- Mobile-friendly interface

## Live Demo

Visit the live site: [E-Commerce Site](https://elepzy.github.io/e-commerce-site/)

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Font Awesome Icons

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Start shopping!
